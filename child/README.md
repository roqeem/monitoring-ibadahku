# ibadahku

Aplikasi Monitoring Ibadah Harian Muslim (Flutter).

## Fitur saat ini

- Login (demo) + onboarding
- Timeline ibadah harian (Hari Ini): shalat fardhu, sunnah, dzikir, doa
- Bacaan doa & dzikir: Arab, Latin, arti, referensi
- Riwayat harian/mingguan/bulanan + statistik & chart
- Jadwal shalat lokal (metode Kemenag & lainnya, koreksi menit)
- Pengingat & azan presisi (alarm) per aktivitas, bertahan setelah restart perangkat
- Mode offline (penyimpanan lokal)
